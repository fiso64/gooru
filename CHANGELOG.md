# Changelog

## [Unreleased]

## [0.1.2]

### Fixed

- Previous/next viewer navigation now traverses the entire filtered library rather than only loaded pages.
- Unmodified grid and viewer shortcuts no longer intercept browser or application shortcuts with extra modifiers, such as Alt+Left and Alt+Right.
- Confirmation and file-tag dialogs wrap long filenames and keep their actions accessible on narrow screens.

## [0.1.1]

### Added

- Named-instance Debian and NixOS administration with `gooru-instance`, dedicated Debian system accounts, and updated service setup instructions.
- Secure persistent default uploads for managed and standalone installations.
- FFmpeg as an explicit runtime dependency of native Debian packages.

### Fixed

- Fullscreen viewer modal and keyboard behavior, adjacent preview after removing media, and tag suggestion navigation.
- Debian, first-run, and stable NixOS deployment documentation.

## [0.1.0]

### Added

- Initial media library release with web browsing, tagging, search, uploads, and a standalone CLI.
